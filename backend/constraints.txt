# requirements.txt ghim gói dùng trực tiếp; tệp này khóa nốt phần còn lại của cây phụ thuộc (starlette,
# pydantic, botocore, cryptography…), để dựng lại sau nhiều tháng vẫn nhận đúng bộ đã kiểm thử. Dockerfile
# cài bằng `pip install -r requirements.txt -c constraints.txt`. Ràng buộc chỉ GIỚI HẠN phiên bản, không tự
# cài thêm gói: gói nào không còn ai cần thì dòng của nó vô hại. Tệp này BẮT BUỘC commit (CLAUDE.md mục 2.3).
#
# Sinh lại mỗi khi đổi requirements.txt — đứng ở gốc kho, cần Docker; ảnh nền cùng dòng FROM của Dockerfile:
#
#     docker run --rm -v "$PWD/backend:/src:ro" python:3.13.17-slim sh -c \
#       "pip install -q --no-cache-dir --root-user-action=ignore --disable-pip-version-check \
#        -r /src/requirements.txt && pip freeze"
#
# rồi thay mọi dòng dưới khối chú thích này bằng đầu ra, dựng lại ảnh và chạy kiểm thử. Git Bash trên
# Windows thêm MSYS_NO_PATHCONV=1 trước lệnh. Bản dưới đây sinh bằng `pip freeze` trong ảnh đang chạy, dựng
# từ requirements.txt hiện tại — nên không đổi phiên bản nào. Không sửa tay từng dòng.
